## Descrição

O projeto consiste no desenvolvimento de um sistema físico gamificado para treinamento de tênis, capaz de criar exercícios dinâmicos de precisão, reação e deslocamento. O sistema utiliza um mecanismo automatizado que sorteia diferentes posições da quadra e direciona o lançamento das bolas, enquanto alvos equipados com sensores identificam os impactos e validam se o jogador atingiu a região correta.

Cada rodada segue uma sequência automatizada de estados, envolvendo sorteio do alvo, movimentação do mecanismo nos eixos X e Y, lançamento da bola, detecção do impacto, validação do acerto e registro do resultado. Os dados coletados são enviados para um aplicativo, permitindo acompanhar pontuação, precisão, tempo de resposta, histórico de jogadas e evolução do jogador.

O aplicativo também disponibiliza aulas e exercícios voltados às dificuldades identificadas durante os treinos. O projeto integra automação, sensores, eletrônica, programação, comunicação entre dispositivos, análise de dados e gamificação aplicada ao treinamento esportivo.
